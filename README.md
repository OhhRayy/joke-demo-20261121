Entry for the [make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

## What it does

`main.py` writes one line — a one-line joke about working beside AI coding
agents — to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The joke:

> My coding agent wrote the fix, had another agent review it, and they both agreed the bug was me.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
